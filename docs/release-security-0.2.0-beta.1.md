# 0.2.0-beta.1 배포 보안 검증

검증일: 2026-11-02 (Asia/Seoul). 이 문서는 수행한 검사와 한계를 기록하며 모든 공격이나 개인정보의 부재를 보장하지 않는다.

## 의존성

- Electron 44.6.0 → 44.10.1: GHSA-jr5w-w6x2-84p9 대응.
- Zod 4.6.5 → 4.6.7: GHSA-mrhx-c7xc-m3w5 대응.
- electron-builder 26.15.3 → 26.18.0 및 호환 가능한 전이 의존성 보안 업데이트.
- npm production audit: 취약점 0건. 전체 audit: 높은/치명적 0건, 중간 15건. 남은 항목은 개발용 패키징 도구의 minimatch 취약점과 그 의존 경로이며 배포 앱의 production dependency에는 포함되지 않는다. 신뢰된 로컬 소스·파일명으로만 빌드하며, 호환성을 깨는 강제 downgrade/override는 적용하지 않았다.
- 참고: https://github.com/electron/electron/security/advisories/GHSA-jr5w-w6x2-84p9 및 https://github.com/advisories/GHSA-mrhx-c7xc-m3w5

## 개인정보와 배포 설정

- 소스와 배포 앱에서 개인 이메일·사용자 폴더 경로·알려진 현재 로그인 비밀값·실형식 Discord webhook·OAuth 비밀값·개인 토큰 및 운영 DB/로그/설정 파일 포함 여부를 점검한다. 원문 비밀값은 검사 결과에 출력하지 않는다.
- 공개 빌드에는 운영자 개인 OAuth 설정을 주입하지 않는다. Google 로그인이 비활성화된 이유를 설정 화면에 안내하며, 기존 LMS/Discord 사용에 Google 로그인을 요구하지 않는다.
- 사용자 자격증명은 Windows Credential Manager에 보관한다. 개인 학사 데이터는 로컬 SQLite에 저장되며 암호화된 DB는 아니다.
- 공개 배포용 커밋은 비공개 개발 이력을 가져오지 않는 별도 배포 브랜치에 생성하며 작성자 이메일은 GitHub noreply를 사용한다. 기존 저장소의 과거 브랜치·태그·릴리스 이력을 지우거나 재작성하지 않는다.

## 검사와 한계

- 타입 검사 및 전체 회귀 테스트 164건, Electron GUI/desktop 25건이 통과했다. GUI 검증의 최초 다운로드 대기는 공식 체크섬을 검증한 캐시 설치 후 재실행하여 해결했다.
- GUI 배포 파일을 명시적 허용 목록으로 제한했다. 테스트 실행 파일이 들어 있는 패키지를 실제로 거부하는 부정 검증을 수행했으며, 실제 최종 패키지의 격리 실행 검사 결과는 릴리스 노트에 명시한다.
- 실제 패키지의 격리 실행 검사 1건 통과: Electron 44.10.1 실행, Google 로그인 비활성·캘린더 OFF, 렌더러 Node 접근 불가, 잘못된 IPC 거부, 계측 이후 외부 요청 0회 및 기존 활성 예약 작업 보존을 확인했다. 예약 작업을 중지해야 하는 별도 OFF 전환 패키지 검사는 사용자의 활성 작업 보존을 위해 1건 건너뛰었으며, OFF 전환 자체는 격리 GUI 및 코어 회귀 검사에서 검증했다.
- 실제 Google 로그인/일정 수정 검수와 다른 Windows 사용자/PC 검증은 미완료다. Google 서비스의 외부 공개 인증도 미완료이므로 정식 Google 연동 서비스로 표시하지 않는다.
- 설치 파일은 코드 서명되지 않았다. 신뢰할 수 있는 공식 릴리스에서만 내려받고 제공된 SHA-256을 비교할 수 있다. SmartScreen을 우회하는 절차는 제공하지 않는다.
